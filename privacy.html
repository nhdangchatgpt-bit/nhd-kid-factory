Privacy Policy

Last updated: 1 November 2026

NHD KID Factory is a personal tool used only by its owner to upload videos to the owner's own YouTube channel through the YouTube API Services.

Data accessed

With the owner's consent, the app uses OAuth access to upload videos, set video details and upload captions on the owner's channel. It does not read, collect or share data about any other person.

Storage

The OAuth token is stored only on the owner's private server and is never shared with third parties.

Revoking access

Access can be removed at any time at Google security settings.

This app uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
